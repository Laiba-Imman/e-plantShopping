# Paradise Nursery Shopping Application

## Project Name

Paradise Nursery Shopping Application

## Description

Paradise Nursery is an online plant shop shopping cart application built with React and Redux Toolkit.

The application allows users to browse different categories of houseplants, view plant information, add plants to a shopping cart, manage quantities and calculate the total cost.

## Features

- Paradise Nursery landing page
- Get Started button
- About Us page
- Three plant categories
- Six unique plants per category
- 18 houseplants in total
- Plant thumbnails
- Plant names
- Plant descriptions
- Plant prices
- Add to Cart functionality
- Disabled Add to Cart button after adding
- Dynamic cart item count
- Shopping Cart page
- Increase quantity
- Decrease quantity
- Delete cart items
- Individual plant total
- Total cart amount
- Checkout Coming Soon message
- Continue Shopping button
- Responsive design
- Redux Toolkit state management
